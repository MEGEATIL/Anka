# Sorun Giderme

- `No module named pytest`: etkin sanal ortamda `python -m pip install -r requirements.txt` çalıştırın.
- `Unable to create process ... Python311`: eski `.venv_new` taşınmış veya silinmiş bir Python kurulumuna bağlıdır. Silmeden önce içindeki gerekli yerel dosyaları yedekleyin; ardından `INSTALLATION.md` ile yeni `.venv` oluşturun.
- Web araştırması çalışmıyor: ağ bağlantısını ve `requests` kurulumunu kontrol edin. ANKA kaynak bulamadığında başarılı araştırma mesajı vermez.
- Kamera açılmıyor: Ayarlar > Gizlilik ve İzinler bölümünde Kamera iznini açın; cihazın işletim sistemi kamera iznini de doğrulayın.
- Sistem işlemi engellendi: Sistem iznini açın ve işlem için gelen açık onayı verin.
